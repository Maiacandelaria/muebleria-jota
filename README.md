# Mueblería Hermanos Jota

Sitio web responsive para la mueblería Hermanos Jota, orientado a mostrar un catálogo de muebles artesanales, sus detalles y canales de contacto.

## Integrantes

- Figueredo,Maia Rita Candelaria
- Peralta Cassutti, Noah Nicanor
- Uriel

## Funcionalidades

- Página de inicio con hero, productos destacados cargados dinámicamente, historia de marca y programa Herencia Viva.
- Catálogo de productos con búsqueda en tiempo real.
- Vista de detalle con información, especificaciones, productos relacionados y carga asíncrona simulada.
- Carrito simulado con selector de cantidad y contador compartido mediante `localStorage`.
- Formulario de contacto con validaciones y confirmación de envío.
- Navbar y footer compartidos, menú accesible para dispositivos móviles e Instagram de la marca.
- Diseño responsive y sistema visual unificado de colores y tipografías.

## Tecnologías utilizadas

- HTML5 semántico
- CSS (Flexbox, Grid y diseño mobile-first)
- JavaScript (DOM, `addEventListener`, `async/await`, `setTimeout` y `localStorage`)
- Google Fonts: Inter y Playfair Display
